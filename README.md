# Online Medicine Store – E-Commerce Healthcare Web Platform

[![Node.js](https://img.shields.io/badge/Node.js-18.x-green.svg)](https://nodejs.org/)
[![Express.js](https://img.shields.io/badge/Express.js-4.x-lightgrey.svg)](https://expressjs.com/)
[![JavaScript](https://img.shields.io/badge/JavaScript-ES6%2B-yellow.svg)](#)
[![REST API](https://img.shields.io/badge/Architecture-RESTful%20APIs-blue.svg)](#)

A full-stack e-commerce healthcare platform featuring product catalog management, category filtering, persistent shopping cart sessions, secure user authentication, and order processing.

---

## 🚀 Key Features

* **Catalog & Filter:** Dynamic product searching, category filtering, and inventory tracking.
* **Cart & Checkout:** Persistent user shopping carts, order summary calculation, and checkout workflows.
* **RESTful Architecture:** Modular backend routes, controllers, and middleware for data validation.
* **Authentication & Middleware:** Secure user authentication sessions and protected customer routes.

---

## 🛠️ Tech Stack

* **Backend:** Node.js, Express.js, REST APIs
* **Frontend:** JavaScript (ES6+), HTML5, CSS3 / Client UI
* **Database & Architecture:** MVC Architecture, Postman, Git & GitHub

---

## ⚙️ Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/aksydv09/Online-Medicine-Store.git](https://github.com/aksydv09/Online-Medicine-Store.git)
   cd Online-Medicine-Store
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the server:**
   ```bash
   node server.js
   ```
